# בדיקות קצה-לקצה

`rehearsal-test.mjs` — חזרה גנרלית: משחק מלא מקצה לקצה בשני חלונות דפדפן.

הרצה (דורש חד-פעמית `npm i -D playwright` ודפדפן Chromium):

```bash
npm run preview &            # שרת על פורט 4174
node tests/rehearsal-test.mjs
```

הבדיקה יוצרת 20 שחקנים, מאגרי שאלות ותמונות, ומריצה את כל ארבעת השלבים
עד הכרזת המנצח — כולל רענון אמצע-משחק לבדיקת שרידות.
