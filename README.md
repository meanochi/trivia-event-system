# פונקט פארקערט — מערכת ניהול משחק הטריוויה

מערכת דו-מסכית להפעלת ערב טריוויה חי: חלון ניהול למפעיל + חלון קהל למקרן.
אפיון מלא: `docs/SPEC.html` · תכנון: `PLAN.md`

## הרצה למפעיל (פיתוח / חזרות)

```bash
npm install
npm run app
```

נפתחים שני חלונות: **מסך ניהול** על המסך הראשי ו**מסך קהל** במסך מלא על המקרן (אם מחובר).
הצלילים והמוזיקה מושמעים מחלון מסך הקהל — חברו אליו את ההגברה.

## בניית קובץ התקנה ל-Windows

מריצים **על מחשב Windows** (פעם אחת לכל גרסה — אפשר לחזור על זה אחרי כל שינוי):

```bash
npm install
npm run dist:win
```

קובץ ההתקנה ייווצר ב-`release/funkt-farkert-setup-<גרסה>.exe` — לחיצה כפולה מתקינה,
יוצרת קיצור דרך "פונקט פארקערט" בשולחן העבודה, והאפליקציה נפתחת אוטומטית בסיום.

> האריזה אינה "חותמת" את הקוד: כל שינוי עתידי בקוד — מריצים שוב `npm run dist:win`
> ומקבלים קובץ התקנה מעודכן.

## פקודות נוספות

| פקודה | תיאור |
|---|---|
| `npm run dev` | שרת פיתוח (דפדפן, `localhost:5174`) |
| `npm run app` | הרצת האפליקציה באלקטרון בלי אריזה |
| `npm run dist:dir` | אריזה ללא התקנה (לבדיקות) |

## מבנה

- `src/core` — מנוע המשחק: מודל, Reducer, Undo, אחסון (IndexedDB), סנכרון (BroadcastChannel), סאונד
- `src/admin` — מסך הניהול (טאבים: משחק, שחקנים, שאלות, הגדרות)
- `src/display` — מסך הקהל (מסכי השלבים, רקע חי, חיוויים, נגן סאונד)
- `electron/` — עטיפת שולחן העבודה (שרת פנימי בפורט קבוע + שני חלונות)
- `docs/SPEC.html` — מסמך האפיון המחייב

## נתונים

כל התוכן (שחקנים, שאלות, תמונות, מוזיקה) מוזן דרך מסכי הניהול ונשמר ב-IndexedDB
מקומי. "איפוס משחק" מוחק את מצב המשחק ואת סימוני "נוצלה" — לא את התוכן.
